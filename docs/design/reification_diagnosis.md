# Reification diagnosis: DataOps

This is a code-grounded, read-only diagnosis. The sharp test used here is whether an operator is both written as graph data and later read back as graph data. Persisting the result of a Python computation does not by itself make the computation reified.

## R1 Judgment memory queryable? — VERDICT: [PARTIAL]

The current centroid and DK state is queryable as data: `copilot_sdk/graph/protocol.py:GraphStore.get_centroids` and `get_dk_weights` expose graph-store state, and `copilot_sdk/scoring/startup_restore.py:restore_l5_runtime_state` loads it back into the scorer. The active metric and its execution remain Python/GAE behavior in `copilot_sdk/scoring/scorer.py:CompoundingScorer._predict`/`score`; the stored tensors are parameters/checkpoints rather than a first-class graph operator that a graph query can execute or explain. Therefore “current metric/weights” is partially remembered, while the judgment operator is not fully queryable as an object.

## R2 Closure (update as graph op)? — VERDICT: [EXTERNAL]

The learning update is executed by the Python/GAE call `copilot_sdk/scoring/scorer.py:CompoundingScorer.learn` → `self._scorer.update` at lines 1024–1030. Its outputs are subsequently written as graph data through `GraphStore.write_outcome`, centroid checkpoints, and DK persistence, but no graph node/edge representing the update rule is read and executed. The graph stores the result and audit trail; it does not currently express the update as an operator acting on itself.

## R3 Multi-hop path reified? — VERDICT: [PARTIAL]

The graph store can traverse data relationships: `copilot_sdk/graph/memory_store.py:MemoryGraphStore.query_context` follows entity–decision links through bounded depths, and `get_decision_links` reads those edges. DataOps decision chains are assembled as Python lists by `copilot_sdk/backend/self_computation_router.py:_decision_chain`; DataOps’s context chain is likewise assembled in `apps/dataops/backend/app/context_router.py` around the `chain` construction at lines 1433–1539. No graph object representing an ordered multi-hop decision process, its hop operators, or a read-back path for the whole composed process was located. A graph has traversable data hops, but the composed decision process is not itself reified.
