## The design decisions
- **D1 (granularity) — agree: fixed set of 4 first.** The Trading detector already emits it; nearest-regime is a trivial exact match; it's demoable. Continuous (Hurst + vol-pct → vector + distance metric) is a v2 — don't gold-plate.
- **D2 (tagging) — agree: string `regime_tag` on checkpoint + decision metadata.** A REGIME node + REGIME_AT edge is over-engineering for 4 regimes (reserve for the continuous case). Land it in the JM-history schema pass (see G2 row).
- **D3 (re-init) — DISAGREE with hard-committing to Option C; make it a measured A/B/C bake-off.** `[OPINION]` The re-convergence *thesis* ("we kept the geometry from the last vol spike") is about the **centroids** (the prototype geometry of good decisions in that regime), not just factor importance. Option C keeps the **current, departing-regime centroids** and swaps only DK weights — arguably the **weakest** for γ>1, since the centroids are what most need to snap to the target regime. **Also: Option C is only buildable if Option B shipped (G2) — DK/τ must be persisted per checkpoint; Option A needs only centroids, which ARE persisted.** So: **don't pick by intuition — let D4/EXP-REGIME measure γ under A, B, and C and pick the winner.** You're running the controlled experiment anyway; this turns a debatable default into a measured result and answers "why this strategy?" with data.
- **D4 (measurement) — agree, with two refinements.** Reuse APP-1's harness (oracle separation, controlled, regime breaks injected); γ = convergence-time ratio. (i) Measure convergence on the **ground-truth-distance** basis (per the CC-1 correction — the oracle-backed *decreasing* curve), not canonical-distance. (ii) **Naming: this γ (regime-break convergence-time ratio) is a different quantity from APP-1's ε_firm re-convergence γ** — the codebase already has an IKS-has-two-meanings problem; don't add a γ-has-two-meanings one. Make D4 the A/B/C bake-off from D3.
- **D5 (conservation) — agree: CALIBRATING + conservative warmup.** The 0.5×V_prior discount is a reasonable default but an untuned hyperparameter — justify/tune it in EXP-REGIME and **err more conservative**: the point of the AMBER throttle is caution on a break, so the discounted V must **not** tip the signal back to GREEN before re-convergence. Verify the reset path exists in the scorer (V-list).
